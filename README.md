The Maze Project is a final output developed for the Data Structures course at De La Salle Lipa. This project demonstrates the application of fundamental data structure concepts—such as stacks, queues, and graphs—in solving and visualizing maze traversal problems. The program is designed to generate or interpret a maze layout, then determine an optimal path from the start point to the exit using efficient algorithms like Depth-First Search (DFS) or Breadth-First Search (BFS).

Beyond algorithmic implementation, the project highlights the students’ understanding of data organization, memory management, and logic formulation. It serves as both a practical and analytical exercise, showcasing how theoretical concepts in Data Structures can be applied to real-world problem-solving and interactive programming tasks.
